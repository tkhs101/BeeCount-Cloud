- 金额 -42.50 / -88,000.00 / -1,234.56,千分位与两位小数都对
- **时区全对**:12:00Z->21:00 / 09:30Z->18:30 / 08:00Z->17:00(全 +9)

  这条证明经过写入->投影->读端->前端渲染整条链后时刻仍正确
- rawKeys: 0,控制台仅预期的 403 admin

三个踩坑(都是我的探针,不是产品):
1. **curl 发中文 payload 报 error parsing the body** —— 判决性对照:同一端点
   ASCII 名成功、中文名失败 = shell 编码把中文弄成非法 UTF-8。
   发中文要用 Python urllib 显式 .encode("utf-8")
2. 写路径是 /write/ledgers/{id}/transactions,字段是 snake_case 且
   base_change_id 必填 —— 猜 camelCase 连撞 400 和 405
3. 原生 setter 设 React 受控输入无效,必须用 playwright-cli fill
